# 🍷 希漫酒业 (Siman Liquor) - Vue.js 项目

## 📋 项目概述

希漫酒业是一个基于 Vue.js 3 的现代化酒业品牌网站，融合了传统酒文化与现代 Web3 技术。项目采用最新的前端技术栈，提供响应式设计、多语言支持、主题切换等现代化功能。

## 🚀 快速启动

### 方法一：使用启动脚本（推荐）
```bash
# Windows
start.bat

# Linux/Mac
chmod +x start.sh
./start.sh
```

### 方法二：手动启动
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 🏗️ 项目架构

### 技术栈
- **前端框架**: Vue.js 3 (Composition API)
- **构建工具**: Vite
- **状态管理**: Pinia
- **路由管理**: Vue Router 4
- **样式预处理**: SCSS/Sass
- **国际化**: 自定义 i18n 解决方案
- **PWA支持**: Service Worker + Manifest

## 🎨 核心功能

### 1. 折叠式导航设计
- **特色**: 创新的折叠式导航，点击"导航"按钮展开下拉菜单
- **位置**: 导航按钮居中显示，带渐变背景和箭头图标
- **响应式**: 支持桌面端和移动端自适应
- **动画**: 平滑的展开/收起动画效果

### 2. 多语言支持
- **支持语言**: 中文、英文
- **切换方式**: 右上角语言切换按钮
- **持久化**: 语言选择保存到本地存储
- **覆盖范围**: 所有页面文本内容

### 3. 主题切换
- **主题类型**: 明亮主题、暗黑主题
- **切换方式**: 右上角主题切换按钮
- **系统适配**: 自动检测系统主题偏好
- **持久化**: 主题选择保存到本地存储

### 4. 钱包连接
- **功能**: Web3钱包连接（模拟实现）
- **状态显示**: 连接状态、钱包地址
- **操作**: 连接/断开钱包
- **位置**: 桌面端显示在右上角，移动端在下拉菜单中

### 5. 响应式设计
- **断点**: 480px、768px、1200px
- **适配**: 手机、平板、桌面端
- **布局**: Flexbox + Grid 布局
- **优化**: 移动端优先设计

## 🔧 开发指南

### 组件开发规范
1. **命名规范**: 使用 PascalCase 命名组件
2. **文件结构**: 每个组件包含 template、script、style 三个部分
3. **注释规范**: 为每个组件添加详细的功能说明注释
4. **响应式**: 所有组件必须支持响应式设计

### 状态管理
- **Store**: 使用 Pinia 进行状态管理
- **命名**: Store 文件使用 camelCase 命名
- **结构**: 包含状态、计算属性、方法三个部分
- **持久化**: 重要状态保存到 localStorage

### 样式规范
- **预处理器**: 使用 SCSS
- **变量**: 所有颜色、尺寸使用 CSS 变量
- **主题**: 支持明暗主题切换
- **响应式**: 使用媒体查询适配不同屏幕

### 路由管理
- **模式**: 使用 HTML5 History 模式
- **守卫**: 全局路由守卫处理页面标题和SEO
- **动画**: 页面切换动画效果
- **错误**: 404页面处理
